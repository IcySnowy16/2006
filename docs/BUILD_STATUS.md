## Not verified

1. **Real Google Maps.** The Directions and Geocoding APIs were never called. The adapter and the geocoding script were tested against pretend answers (including a recorded Directions response shape).
2. **Real e-mail.** Tested against the Mailpit container only. No real SMTP provider, and no message to a real @e.ntu.edu.sg inbox (university filters may reject or junk it).
3. **Push notifications.** Not implemented. The `web-push` package was skipped (last release January 2024, MPL licence). The flag is off and the in-app list is the fallback.
4. **A real phone.** The app was walked in headless desktop Chrome with a pretend location. Phone geolocation, the screen wake lock, installing the app, offline reload and a Lighthouse run were not done.
5. **Hosting.** Nothing is deployed. The Docker image was built and run locally (health, migrations, app, service worker). Cookies over a real https host, the WebSocket through a host's proxy, idle sleep and database expiry are unchecked.
6. **GitHub.** CI and release workflows have not been run by GitHub Actions (their commands were run locally). Branch protection and the required check are not set. This draft branch is not pushed; no pull request exists for it.
7. **Scantist.** No scan was run; it needs your own account.
8. **Second machine.** The README / `npm run dev` path was run on one laptop only; the task asks for a second teammate's machine.
9. **The campus data.** The catalog has names but no coordinates, and there is no campus boundary file. Nothing about the real campus map was verified.
10. **SRS documents.** Appendix D (error catalog) and the traceability table exist as generated files; they were not pasted into the SRS. Mockups, class diagram work and the other non-code tasks were not touched.
11. **Scale and speed.** Seat and wallet races were tested on one server process with up to six simultaneous requests. No load test, no multi-process test, and the 3-second matching and 1-second throttle limits were not measured under load.
12. **Accessibility.** Labels, roles and focus handling are tested, but there was no screen-reader or colour-contrast audit.
13. **Dependency advisory.** The Prisma CLI pulls in a dev-only package (deepmerge-ts) with a known advisory; it is not part of the running server. `npm audit --omit=dev` is what CI checks.
14. **Task board.** docs/tasks.csv and docs/tasks.md were not updated with these statuses.
